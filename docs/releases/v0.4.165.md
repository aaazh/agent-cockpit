# Agent Cockpit v0.4.165

## Shipped For Users

- Grok Build is now a supported CLI harness. Set up a **Grok Build** CLI profile in Settings and use it from the desktop or mobile composer, either reusing your existing `grok` terminal login or installing the CLI and signing in with device authorization from the Welcome screen. Conversations support visible thinking, tool activity, grouped subagents that keep working in the background, clarifying questions, plan approval with revision feedback, mid-turn input, and native goals you can pause, resume, and clear.
- Grok Build works with Agent Cockpit Memory, Knowledge Base, Workspace Context, and Workspace Routines, and accepts image and PDF attachments on `grok-4.7`. Usage shows token and context totals, Grok's reported model cost when it is complete, and optional account details such as tier, credit use, prepaid balance, and reset date. Goal token budgets are labeled as soft limits because Grok can exceed them.
- Grok Build compatibility is verified with Grok Build 1.0.52 on macOS (Apple silicon). Windows and Linux support is covered by automated tests but has not yet been validated on native machines.
- Claude Code profiles can now use Claude Opus 5.5 (1M context), Sonnet 5.5, and Fable 5.1. Sonnet 5.5 is the new default, and Opus 5, Sonnet 5, and Fable 5 remain available as previous models.
- Usage estimates now price Claude Opus 5.5, Sonnet 5.5, and Fable 5.1 at their own rates, add GPT-6.1 Sol, GPT-6 Sol, GPT-6 Luna, and the Daybreak Blue alias, and refresh GPT-6 Astra and GPT-5.6 rates, including 272,000-token long-context pricing.
- Mobile plan approvals now use explicit **Approve & run** and **Reject** buttons, so a typed reply is never mistaken for approval. On desktop and mobile, a follow-up question or revised plan that arrives while your previous answer is still sending no longer disappears.
- Mobile download cards now appear only for files the assistant delivers, not for file-delivery markers quoted in your own message, and the mobile usage bar shows `n/a` instead of `$0.0000` when no cost is available.
- Dependency security updates harden file uploads, Knowledge Base PowerPoint imports, client-address handling behind proxies and tunnels, and rendered Markdown sanitization.

## Developer Details

- Added the `grok-build` harness through ACP version 1 plus native `_x.ai/*` extensions, split across focused `src/services/backends/grok*.ts` modules for transport, runtime/auth, process ownership, events, interactions, models, usage, goals, and billing. The adapter leases one runtime per conversation, recovers missing native sessions from Cockpit snapshots only on `FS_NOT_FOUND`, never retries interrupted tool work, tracks detached POSIX descendants for cleanup, and requires a zero-tool preflight before restricted one-shots. ADR-0092 records the integration decision; `docs/spec-grok-build.md` and `docs/research/grok-build-acp-evaluation.md` hold the behavior contract and protocol evidence. See [#556](https://github.com/daronyondem/agent-cockpit/pull/556).
- Grok Build is wired into CLI profiles (`setup-grok-build-account` shares `~/.grok`; explicit account profiles map `configDir` to `GROK_HOME`), remote device-auth jobs with xAI key redaction, Install Doctor (`grok-cli` check and `grok-cli:npm-install` action), CLI updates (npm-global or native `grok update --check --json` / `grok update`), the Windows command resolver and private-Node terminal wrappers, data-migration post-import checks, and the new `GET /api/chat/cli-profiles/:profileId/grok-billing` endpoint with its browser-safe `src/contracts/grokBilling.ts` contract. See [#556](https://github.com/daronyondem/agent-cockpit/pull/556).
- Shared client changes: mobile plan decisions moved into `mobile/AgentCockpitPWA/src/interactionCard.tsx`, and `useSendPipeline.submitInteraction(answer?)` sends the button decision instead of typed text. Desktop `streamStore.js` and the mobile send pipeline clear only the interaction they answered, the desktop default usage card includes cache read/write tokens, and goal objective normalization recognizes Grok harness names. See [#556](https://github.com/daronyondem/agent-cockpit/pull/556).
- Added deterministic Grok suites (`grokProtocol`, `grokEvents`, `grokBackend`, `grokInteractions`, `grokIntegration`, `grokProcess`, `grokWindows`, `grokUi`) with the `test/fixtures/grok-acp.cjs` CLI fixture, plus opt-in native suites through `npm run e2e:grok-build` and `npm run e2e:grok-build-ui`. Coverage thresholds rose to 87% statements/lines, 74% branches, and 93% functions. See [#556](https://github.com/daronyondem/agent-cockpit/pull/556).
- Added Claude Opus 5.5 (`claude-opus-5-5[1m]`), Sonnet 5.5 (`claude-sonnet-5-5`, new default), and Fable 5.1 (`claude-fable-5-1`) to the Claude Code catalog. Their pricing entries sit ahead of the broader `*claude-opus-5*`, `*claude-sonnet-5*`, and `*claude-fable-5*` globs so first-match resolution picks the newer rates. The OpenAI catalog uses the September 29, 2026 standard and Fast rows with 272K long-context tiers. See [#544](https://github.com/daronyondem/agent-cockpit/pull/544).
- Brought user and developer docs up to date for these changes, moved the account-profile config-directory copy into `web/AgentCockpitWeb/src/screens/cliProfileConfigDir.js` (fixing the Grok Build hint), taught the Windows installer repair rerun to rewrite `grok.ps1`/`grok.cmd`, and restored the `BACKENDS.md` Codex feature table. See [#557](https://github.com/daronyondem/agent-cockpit/pull/557).
- Release preparation updated lockfiles for patched `adm-zip` 0.6.1, `multer` 2.4.0, `proxy-addr` 2.0.8, `dompurify` 3.4.17, `handlebars` 4.7.10, `ip-address` 10.7.4, `source-map-js` 1.2.2, and `brace-expansion`. It also added root npm overrides `js-yaml = 4.3.2` and `basic-ftp = 6.2.3`, because PM2 7.0.4's exact dependency pins and the Jest coverage loader's ranges keep lockfile updates from reaching those fixes. The `js-yaml` override also removes the `argparse` 1.x / `sprintf-js` chain. The only breaking change in `basic-ftp` 6.0 disables separate FTP transfer hosts by default, which PM2's `proxy-agent` → `get-uri` path does not rely on. A PM2 start/restart/delete smoke test from a YAML ecosystem file passed with the overrides. The patched DOMPurify adds 2.3 KiB to the Markdown vendor chunk, so the total JS bundle ceiling in `scripts/check-web-bundle-size.js` rose from 895 KiB to 900 KiB to cover the patched build (897.1 KiB).
- Accepted exposure: `braces` [GHSA-vfj7-8cjw-p6xm](https://github.com/advisories/GHSA-vfj7-8cjw-p6xm) (high) remains through `pm2@7.0.4` → `chokidar@3.6.0` → `braces@3.0.3`. No patched `braces` release exists, PM2 pins `chokidar` exactly, and `npm audit fix --force` would downgrade PM2 to 2.9.3. The advisory is a denial of service on deeply nested glob patterns; Agent Cockpit does not use PM2 watch mode, and no untrusted input reaches those patterns. Exposure analysis and follow-up plan: [#558](https://github.com/daronyondem/agent-cockpit/issues/558).
